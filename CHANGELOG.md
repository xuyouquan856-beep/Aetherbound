# Changelog

## 0.5.0-beta.1

First public Windows preview.

- TXT and EPUB reading with bookmarks, highlights, notes, quotations, book search, and EPUB image directory.
- Library import, folder scanning, duplicate review, collections, and series organization.
- Night-sky library interface with adjustable crystal collection colors and motion controls.
- Offline x64 Windows installer and ZIP package. Uninstall keeps the user's library profile.

The preview installer is currently unsigned and updates are installed manually. No book files or personal library are included in the release.
